Import dashboard data

Zip the output/site folder the pipeline builds and import it here. The bundle is stored in the database; viewers then read it live.

Must contain dse-data/manifest.json, core.bin and c/

Browser import is disabled on this deployment because publishing a bundle takes longer than the platform allows. To publish new data, run this on the machine that holds the project files:

python publish_site.py

Data processing

Server-side ETL is disabled on this deployment: it needs a writable checkout and a long-lived process, which serverless does not provide. To refresh the data, run the pipeline on the machine that holds the project files and publish the result:

python publish_site.py
